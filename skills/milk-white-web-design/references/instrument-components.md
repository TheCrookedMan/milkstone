# 刻度与实体控件
下述灰白表面、文字、半透明白边与柔影以默认 light 为基准；dark 使用对应深色主题，milk 使用牛奶柔白与浅暖灰层次，仍是左上受光、右下投影、凸面较亮、凹槽较暗；边框宽度与交互几何保持。light 与 dark 的阴影几何相同，milk 通过更短偏移、更小模糊和紧密接触影让按键更凝实，见 [三种主题](theme-modes.md)。

文字像刻印、Tab 像凹槽中的拨片、数值像仪表读数。浅灰表面以深蓝灰实心字、字重、排版和刻度表达刻印感，文字保持清楚；主按钮使用深色字，正文与读数保持可读对比。大字号数字可用等宽字，普通中文保持正常字重。

实体按键采用紧凑胶囊外形、1px 半透明白边与浅灰凸面，左上白色高光和右下灰色柔影形成浮起感。按钮使用 --milk-button-shadow，悬浮使用 --milk-hover-shadow，按压切到 --milk-pressed 并保留小幅位移；小型功能槽使用 --milk-control-shadow。Tabbar 整体为 recessed 凹槽，选中拨片使用 raised 表面与按钮外浮阴影，未选中项融入槽面；输入及读数窗同样使用内凹表面与阴影。刻度、文字和明确位置反馈区分状态，不再绘制硬侧面底座；milk-relief 类仅作兼容，depth 为 0。仅实际输入框聚焦时沿已有边框内侧显示柔和渐变流光，复合输入只在编辑器聚焦时装饰一处可见边界，内部按钮聚焦不亮起。按钮、Tab、下拉触发器、开关和滑杆不新增焦点边框或流光，原有实体材质、选中／拨动状态及几何保持；输入框成功接管时取消额外外围 outline／ring，未接管时仅输入框保留静态键盘边界回退，见 [焦点规范](design-system.md)。Reka Tabs 负责 roving focus、左右键、选中与内容语义，不手写无键盘行为的 role=tab。

旋钮 SVG 仅是原生 range 的读数，键盘与辅助技术操作 range。刻度以亮度和长度区分主次并标明范围。开关使用 checkbox + role=switch，保留可见名称与原生勾选状态；开启时使用低饱和玉绿色槽面与“开”，关闭时使用中性灰槽面与“关”，同时以拨片位置区分，不能只靠颜色表达状态。槽面与文字复用 --milk-switch-on-surface／--milk-switch-on-ink 和 --milk-switch-off-surface／--milk-switch-off-ink，随主题校准并保留原有凹槽与浮起拨片；装饰性“开／关”文字使用 aria-hidden，避免覆盖控件名称或重复播报。灰阶状态灯配文字。不要在全部留白里重复刻度装饰。

按键采用轻微机械阻尼：100ms 按下，至少 112ms 浅凹反馈，420ms 平稳回位；默认位移 2px、缩放 0.975，Tab 位移 1px，开关原位缩放 0.98，保持选中位置清楚。由共享 press-controller.ts 管理鼠标、触摸和键盘短暂状态，组件不重复增加计时器，不延迟按钮业务操作。旋钮的 range 和 SVG 不接按键动效，减少动态效果时取消运动并保留即时材质反馈，具体曲线见 [交互规范](motion-and-network.md)。

assets/components/InstrumentControls.vue 自带 scoped 样式并引用 milk-tokens.css。按业务替换电源、强度与启动行为；示例状态在内存，不控制真实硬件。
