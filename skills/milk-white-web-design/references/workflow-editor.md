# 浅灰柔和拟物工作流编辑器

需要节点拖拽、端口连线、参数检查与可交换 JSON 时，复制 `assets/components/WorkflowStudio.vue`、`assets/workflow-model.mjs` 及 `assets/workflow-model.d.mts`，保留相对目录。示例使用 Vue Flow 1.48.2，直接导入核心样式，自带 scoped 浅灰柔和拟物皮肤；安装 `@vue-flow/core@1.48.2` 即可。组件从技能源码被落地页直接导入，避免维护另一份演示实现。

## 已实现的编辑行为

- 桌面支持平移、按钮缩放、自动适应、拖动、端口连接、节点与连接删除。Vue Flow 节点可用 Tab 聚焦，再用 Enter/Space 选择、方向键移动。保留可见焦点轮廓。
- 参数面板编辑节点标题与 `widgets_values` 的字符串、数字、布尔值；复杂值通过原始 JSON 编辑。所有数据保存在当前浏览器页面内存，刷新会恢复示例。
- 连接前检查源/目标存在、端口类型、单输入约束及无环拓扑。参数面板提供四个原生 select 与连接按钮，供键盘和触屏完成同一操作。
- 提供添加提示词、移除节点、移除连接、重置、文本/文件导入与下载。移除节点同步移除关联连接。
- “运行模拟”按拓扑顺序改变节点状态，可停止；它只演示本地状态流转，不执行模型推理、不读取模型文件、不生成图像。界面持续显示“无生成后端”。
- 760px 及以下改为纵向节点列表和完整参数面板，继续支持连接、删除、导入导出和模拟。避免把不可操作的缩小画布当移动端方案。

画布在桌面/移动切换时用 `v-show` 保持挂载，列表按需呈现，保留同一份图数据。新增连接校验绑定到 `Handle`；Vue Flow 1.48.2 的全局 `isValidConnection` 也会用于 `setEdges()` 加载已有连接，不能在那里把已存在的边当作一条新边再次插入验证，否则会被单输入约束错误拒绝。重置、导入与断点切换后都应核对连接数量。

## ComfyUI 数据兼容范围

依据 [ComfyUI Workflow JSON 0.4 官方规范](https://docs.comfy.org/specs/workflow_json_0.4)，本原创适配器支持明确的前端格式子集：版本为 `0.4`、1–100 个节点、至多 400 条连接；节点位置/尺寸使用两个数字的数组，端口索引使用非负整数，节点 id 为非空字符串或非负整数。`last_node_id` 与 `last_link_id` 必须存在。支持字符串、数字及字符串数组的端口类型，`*` 可连接任意类型；输入端口只允许一条连接。

保留原始 `nodes` 中的未知字段、`properties`、数组或对象形式的 `widgets_values`，以及顶层额外元数据。未知节点类显示通用参数卡。导出重建六元 `links`、各输入的 `link`、各输出的 `links`、执行排序与计数器；移动位置四舍五入为像素整数。导入的节点原尺寸被保留，编辑器用统一卡片宽度呈现。组、颜色、折叠标记、额外扩展元数据仅保留，不提供对应编辑视图。

不支持 API prompt 格式、其他 workflow 版本、子图执行语义、环路或第三方自定义控件。通用类型检查不能替代 ComfyUI 的节点定义、模型存在检查或后端参数验证。默认图使用常见原生节点类型及占位模型文件名；用户必须在真实 ComfyUI 环境选择已有模型并验证后再运行。不能将“可导入 JSON”描述为“已集成 ComfyUI 生成服务”。

## 与真实后端连接时

先确定用户已有的 ComfyUI 地址、节点定义与鉴权方式。前端 workflow 文件和后端 API prompt 是不同的数据契约；不要把前端 `nodes` / `links` 原样提交成 API prompt。按真实节点定义转换端口和 widgets，使用用户指定后端的队列、进度、错误与取消能力，并将本地模拟状态和远端实际执行状态分开。外部执行与模型下载应服从用户当前授权范围。

## 实体视觉约定

以下材质说明以默认白色模式为基准；黑色模式通过控制器及语义令牌适配 Vue Flow 节点、端口、连线、画布与 Portal，维持左上受光、右下投影，节点凸起、参数槽内凹；材质颜色和透明度可校准，节点坐标、参数和选中状态不变，见 [双模式主题](theme-modes.md)。

画布刻度位于 #e4e6eb 浅灰凹槽内；工作台与节点 Card 使用圆角灰白表面、1px 半透明白边和 --milk-card-shadow 外浮柔影，可点击卡片悬浮使用 --milk-card-hover-shadow。操作按钮是紧凑胶囊，复用 --milk-button-shadow 与 --milk-hover-shadow；参数输入框和读数窗使用 recessed 表面与 --milk-pressed 内凹阴影。左上白色高光与右下灰色投影形成柔和层次，不再绘制伪元素硬底座；milk-relief 保留兼容，depth 为 0。主操作采用 #eef0f4 凸面与深蓝灰字。节点编号和参数读数嵌入灰白底面，标签以实心字、字重和排版呈现刻印感；极轻纸纹不能干扰节点、刻度与连线。连接线用灰阶亮度与实虚线区分状态，端口套圈保持清楚；选中使用表面变化与明确标识，节点与按钮保留可见键盘 outline；参数输入与下拉控件以内部材质和状态反馈聚焦，不显示最外层 outline、ring 或焦点边框变色，正常边框及柔影保持，运行、成功和错误配明确文字，减少动态效果模式关闭位移动效。
