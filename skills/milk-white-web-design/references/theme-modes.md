# 白色、黑色与乳白风格

三种风格使用同一套柔和拟物设计，背景、主题和文本按材料角色切换，凸起与凹槽的光照关系保持一致。light（白色）使用冷灰纸底、协调灰白表面和深色文字；dark（黑色）使用深炭灰底、层次清楚的深灰表面和浅色文字；milk（乳白）使用牛奶般的柔白基底、暖白受光面和浅暖灰凹槽。黑色按材料角色调配颜色，不对所有像素机械取反；乳白是一套独立的浅色材料配方，不在整页叠加黄色滤镜。

## 独立的毛玻璃材质

配色仍只有 light、dark、milk 三项；毛玻璃由独立的 `solid`／`glass` 材质开关叠加，允许六种组合。`data-theme` 与 `milk-design-theme` 只管理配色，`data-material` 与 `milk-design-material` 只管理材质，切换其中一项不改写另一项，也不重置组件数据或动画相位。默认使用实面；毛玻璃沿用相同光照、凸起和凹槽、尺寸、排版及按压反馈，只调整语义表面的透明度、背景虚化与边缘高光。控制器、样式顺序、局部展示和回退见 [毛玻璃材质](glass-material.md)。

完整颜色、透明度和阴影数值以 `assets/milk-tokens.css` 为准。三种风格均保持左上受光、右下投影；凸面比相邻基底亮，凹槽比相邻基底暗，选中 Tab 拨片继续浮起。外浮阴影的左上高光不能在 dark 中变成黑影，右下投影也不能变成白色光斑；内凹槽保留左上内暗、右下内亮的遮光关系。默认、悬浮、按压、聚焦、选中、禁用、加载和错误状态复用相同材料角色与行为。

高光、阴影、边框和表面渐变的颜色与透明度按相近的感知深度校准。圆角、尺寸、间距、字体、纸纹密度、布局、组件状态、位移、持续时间与动画相位保持；八类阴影的光照方向，以及表面渐变方向与色标位置保持。light 与 dark 保持相同阴影偏移、模糊和扩展；milk 在同一角色体系内采用更短偏移、更小模糊与紧密接触影，收紧阴影范围。组件状态样式只写一份，暗色与乳白校准集中在同一语义令牌体系中，不复制另一套组件几何或交互。

普通外框保持 1px，图片区 rim 保持 3px，dark 中保留其受光边含义而不是直接变成黑边。milk-relief 类仅保留兼容、depth 为 0，不构建硬底座。仅实际输入框在三种风格与 Portal 内沿已有边框内侧显示统一柔和渐变流光，复合输入只在编辑器聚焦时装饰一处可见边界，内部按钮聚焦不亮起，PIN/OTP 跟随活动格。输入框成功接管时取消额外外围 outline／ring，未接管时仅输入框保留静态键盘边界回退。按钮、链接、Tabs、Select、Checkbox/Radio/Switch、Slider/Range 及容器等其他元素不新增焦点边框或流光，正常材质边框、柔影和选中状态保持，见 [焦点规范](design-system.md)。

## 乳白的材料规范

milk 保留清爽柔白的主观感受，只加入很轻的暖灰层次，避免奶黄色、旧纸棕色或纯白整片铺满。画布与面板保持相邻色温；左上高光为暖白，右下投影为克制的暖灰。正文采用深灰褐，次字仍有清晰对比，不用浅米色文字营造柔和。外浮 Card 与按钮、内凹输入和 Tabbar、选中拨片及 Portal 均复用同一材料角色；乳白采用短距离暖灰投影、紧贴边缘的接触影与内侧暖白薄高光，让卡片和按键更凝实。Card 常态外影模糊不超过 7px、悬浮 8px；按钮常态 3px、悬浮 4px；按压与控件内凹 3px；浮层 12px。接触影为 1–2px 模糊，完整参数以 milk-tokens.css 为准。保留柔和边缘，不构造硬底座或黑色重边。纸纹密度、字阶、间距、尺寸和阻尼参数保持。Switch 继续用玉绿色加“开”、中性槽面加“关”表达真实状态，不随乳白主题丢失辨识。

## 控制器与选择器

复制 [主题控制器](../assets/theme-controller.ts)、`assets/theme-colors.css`、`assets/milk-tokens.css` 和 [模式开关](../assets/components/ThemeModeSwitch.vue) 时保持源码依赖关系。主题控制器初始化 `html` 的 `data-theme="light"`、`data-theme="dark"` 或 `data-theme="milk"`；未有已记住的有效选择时使用 `light`。用户切换后以 `milk-design-theme` 为 localStorage 键保存选择，刷新后恢复。受限存储环境仍应允许当前页面切换，不把存储失败伪称为已记住。

控制器提供以下入口，实际类型与默认参数以源码为准：

| 入口 | 用途 |
| --- | --- |
| `initTheme` | 启动时初始化模式、根属性和已记住的选择 |
| `getTheme` / `isDark` | 获取当前模式或判断是否为黑色模式 |
| `setTheme` | 设置 `light`、`dark` 或 `milk`，同步根属性与选择记录 |
| `invertHex` | 保留 RGB 逐通道反相与 alpha 不变的工具函数，用于确需互补色的兼容或数据用途 |
| `themeColor` | 保留按当前模式转换基准颜色的兼容函数，不用于反转实体光照、图片或自然场景 |
| `useTheme` | 在 Vue 组件中连接响应式模式状态 |

变化时在 `window` 派发 `milk-theme-change` 事件，独立绘制器可据此重绘。`assets/components/ThemeModeSwitch.vue` 保留兼容文件名，使用可访问名称为“界面风格”的 radiogroup，内含“白色风格”“黑色风格”“乳白风格”三个原生 radio；每个实例使用独立的组名，支持 Tab 进入和方向键选择。当前选项与刷新后的页面模式一致。milk 的浏览器 color-scheme 为 light，isDark 返回 false；兼容的 useTheme.toggle 仍按深浅二态切换，三选项界面使用 setTheme。切换风格不重置组件选择、编辑数据或动画相位。

## DOM、Portal 与绘制器

实体表面、凹槽、高光、投影、边框与文本通过 `milk-tokens.css` 的语义角色和 `html[data-theme]` 切换。新增实体样式优先使用 `--milk-surface-raised`、`--milk-surface-recessed`、八类阴影及边框令牌，不把自动生成的十六进制互补色当成材质规则。`theme-colors.css` 和 `themeColor` 的互补色能力保留兼容，不等于所有渲染内容都应反色。不要使用整页 `filter: invert(...)`。

Dialog、Popover、菜单、通知等 Portal 继承根主题属性及语义令牌；覆盖传送后的根节点，不能只修改页面内的外壳。shadcn 的 surface、text、ring、chart、边框与柔影映射到相同角色。引入上游组件时检查其 `dark:` 工具类，移除与统一材料角色、输入框专属焦点边界及其他元素无新增焦点框的规则冲突的差异，透明度校准留在统一令牌中。

SVG、ECharts、Unovis 与 Vue Flow 的文本、背景、网格、关系线及数据系列按语义角色适配当前主题；已解析 CSS 颜色直接使用，不能再次互补。Canvas 2D 与 WebGL 保持自然照明：太阳及日冕仍发光，行星受光侧仍亮、背光侧仍暗，建筑亮层与扫描光保持发亮，图片保持原内容。发光核心使用跨模式保持明亮的 `--milk-emission`；背景、轨道、坐标与标签按对比需求适配，不对整个画面或最终着色器输出取反。

模式变化后更新图表选项或重绘已有场景，监听与订阅在卸载时清理。纹理坐标、轨道、自转、公转、投影和扫描相位保持原样；减少动态效果或暂停时也要能响应一次主题重绘。独立示例与根落地页使用相同语义令牌，移植领域组件时保留控制器、颜色 CSS 和依赖它们的组件文件。

## 验证

分别检查首次打开的默认白版、切为黑版与乳白版、每种选择的刷新恢复以及切回白版。对根页面、Card、按钮、Tabbar、输入框、图片和打开后的 Portal，在同一状态与视口比较计算样式和实际视觉；覆盖默认、hover、active、focus、选中、禁用、错误与浮层打开状态。确认暗色与乳白背景上的文本均清楚可读，左上高光和右下投影方向一致，凸面高于基底、输入和 Tabbar 仍内凹，选中拨片仍浮起，不能以所有颜色通道相加为 255 作为验收标准。

核对白色与黑色的阴影几何保持，乳白的阴影范围更小、边缘更凝实且方向一致；三者的边框宽度、圆角、表面渐变位置、字体、布局及交互保持，输入框焦点光效贴合边框内侧且不改变几何，成功接管时没有额外外圈，未接管时仅输入框有静态键盘边界回退；其他元素聚焦无新增边框，复合输入内部按钮不使外层亮起。再检查图表对比、关系线、电流亮核、星体火焰和昼夜面、建筑扫描亮层与工作流；发光不能变黑、图片不能变负片，数据与操作状态保持。记录实际验证的绘制器与回退路径，未执行项单独说明。
