# 白色与黑色风格切换

两模式使用同一套柔和拟物设计，背景、主题和文本切换为对应的浅色／深色配色，实体感与凹槽感保持一致。light 使用浅灰纸底、协调灰白表面和深色文字；dark 使用深炭灰底、层次清楚的深灰表面和浅色文字。黑色模式按材料角色调配颜色，不对所有像素机械取反。

## 材料与光照

| 角色 | light | dark |
| --- | --- | --- |
| 画布 `--milk-canvas` | `#e9eaee` | `#1c1f24` |
| 面板 `--milk-panel` | `#ebedf1` | `#24282e` |
| 凸面 `--milk-raised` | `#eef0f4` | `#2a2e35` |
| 亮面 `--milk-light` | `#f4f5f8` | `#333841` |
| 凹槽 `--milk-inset` | `#e4e6eb` | `#181b20` |
| 深面 `--milk-depth` | `#dfe2e8` | `#121519` |
| 正文 `--milk-ink` | `#2e3540` | `#edf0f5` |
| 发光 `--milk-emission` | `#fbfcff` | `#fbfcff` |

完整颜色、透明度和阴影数值以 `assets/milk-tokens.css` 为准。两模式均保持左上受光、右下投影；凸面比相邻基底亮，凹槽比相邻基底暗，选中 Tab 拨片继续浮起。外浮阴影的左上高光不能在 dark 中变成黑影，右下投影也不能变成白色光斑；内凹槽保留左上内暗、右下内亮的遮光关系。默认、悬浮、按压、聚焦、选中、禁用、加载和错误状态复用相同材料角色与行为。

高光、阴影、边框和表面渐变的颜色与透明度按相近的感知深度校准。圆角、尺寸、间距、字体、纸纹密度、布局、组件状态、位移、持续时间与动画相位保持；八类阴影的方向、偏移、模糊和扩展范围，以及渐变方向与色标位置保持。组件状态样式只写一份，暗色校准集中在同一语义令牌体系中，不复制另一套组件几何或交互。

普通外框保持 1px，图片区 rim 保持 3px，dark 中保留其受光边含义而不是直接变成黑边。milk-relief 类仅保留兼容、depth 为 0，不构建硬底座。实际聚焦控件在两模式与 Portal 内均沿已有边框内侧显示统一冷白蓝荧光流动效果，复合输入仅装饰一处可见边界，PIN/OTP 跟随活动格，正常边框几何与柔影保持；成功接管时取消额外外围 outline／ring，未接管时保留可见键盘 outline 回退，见 [焦点规范](design-system.md)。

## 控制器与开关

复制 [主题控制器](../assets/theme-controller.ts)、`assets/theme-colors.css`、`assets/milk-tokens.css` 和 [模式开关](../assets/components/ThemeModeSwitch.vue) 时保持源码依赖关系。主题控制器初始化 `html` 的 `data-theme="light"` 或 `data-theme="dark"`；未有已记住的有效选择时使用 `light`。用户切换后以 `milk-design-theme` 为 localStorage 键保存选择，刷新后恢复。受限存储环境仍应允许当前页面切换，不把存储失败伪称为已记住。

控制器提供以下入口，实际类型与默认参数以源码为准：

| 入口 | 用途 |
| --- | --- |
| `initTheme` | 启动时初始化模式、根属性和已记住的选择 |
| `getTheme` / `isDark` | 获取当前模式或判断是否为黑色模式 |
| `setTheme` | 设置 `light` 或 `dark`，同步根属性与选择记录 |
| `invertHex` | 保留 RGB 逐通道反相与 alpha 不变的工具函数，用于确需互补色的兼容或数据用途 |
| `themeColor` | 保留按当前模式转换基准颜色的兼容函数，不用于反转实体光照、图片或自然场景 |
| `useTheme` | 在 Vue 组件中连接响应式模式状态 |

变化时在 `window` 派发 `milk-theme-change` 事件，独立绘制器可据此重绘。`assets/components/ThemeModeSwitch.vue` 使用 `role="switch"`、`aria-label="黑色风格"` 和对应的 `aria-checked`；关闭为白色模式，开启为黑色模式。开关可由键盘操作，刷新后的状态与页面模式一致。切换风格不重置组件选择、编辑数据或动画相位。

## DOM、Portal 与绘制器

实体表面、凹槽、高光、投影、边框与文本通过 `milk-tokens.css` 的语义角色和 `html[data-theme]` 切换。新增实体样式优先使用 `--milk-surface-raised`、`--milk-surface-recessed`、八类阴影及边框令牌，不把自动生成的十六进制互补色当成材质规则。`theme-colors.css` 和 `themeColor` 的互补色能力保留兼容，不等于所有渲染内容都应反色。不要使用整页 `filter: invert(...)`。

Dialog、Popover、菜单、通知等 Portal 继承根主题属性及语义令牌；覆盖传送后的根节点，不能只修改页面内的外壳。shadcn 的 surface、text、ring、chart、边框与柔影映射到相同角色。引入上游组件时检查其 `dark:` 工具类，移除与统一材料角色、统一荧光边框与键盘焦点回退规则冲突的差异，透明度校准留在统一令牌中。

SVG、ECharts、Unovis 与 Vue Flow 的文本、背景、网格、关系线及数据系列按语义角色适配当前主题；已解析 CSS 颜色直接使用，不能再次互补。Canvas 2D 与 WebGL 保持自然照明：太阳及日冕仍发光，行星受光侧仍亮、背光侧仍暗，建筑亮层与扫描光保持发亮，图片保持原内容。发光核心使用跨模式保持明亮的 `--milk-emission`；背景、轨道、坐标与标签按对比需求适配，不对整个画面或最终着色器输出取反。

模式变化后更新图表选项或重绘已有场景，监听与订阅在卸载时清理。纹理坐标、轨道、自转、公转、投影和扫描相位保持原样；减少动态效果或暂停时也要能响应一次主题重绘。独立示例与根落地页使用相同语义令牌，移植领域组件时保留控制器、颜色 CSS 和依赖它们的组件文件。

## 验证

分别检查首次打开的默认白版、切为黑版、刷新恢复以及切回白版。对根页面、Card、按钮、Tabbar、输入框、图片和打开后的 Portal，在同一状态与视口比较计算样式和实际视觉；覆盖默认、hover、active、focus、选中、禁用、错误与浮层打开状态。确认暗色背景与文本可读，左上高光和右下投影方向一致，凸面高于基底、输入和 Tabbar 仍内凹，选中拨片仍浮起，不能以所有颜色通道相加为 255 作为验收标准。

核对阴影几何、边框宽度、圆角、渐变位置、字体、布局及交互保持，控件焦点光效贴合边框内侧且不改变几何，成功接管时没有额外外圈，未接管时仍有可见键盘回退。再检查图表对比、关系线、电流亮核、星体火焰和昼夜面、建筑扫描亮层与工作流；发光不能变黑、图片不能变负片，数据与操作状态保持。记录实际验证的绘制器与回退路径，未执行项单独说明。
