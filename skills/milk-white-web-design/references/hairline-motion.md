# 线框造型与动效

为 Empty 插图、图谱选择和工作流状态实现线框动效时读取本文件。Hairline 的固定绘图内核用于插图；关系图和 Vue Flow 继续使用各自的数据与渲染方式，复用动作组织原则。现有按钮保留短时机械阻尼，不把图形的运动时长套到所有控件。

## 先确定静止造型

用完整物件表达缺席的内容：空图表承载暂无数据，空名册架承载暂无用户，放大镜与空白纸面承载无搜索结果；空托盘保留为通用可选图。物件与交互对应同一含义，静止时也应可辨；业务标题、原因和下一步由外层组件提供。按场景选择默认图形或用户保存的作品，不让不同空状态只能共用一个占位符。

三维坐标经固定投影变成二维 SVG 路径。外轮廓、内折线和退后线使用不同层次，圆角、厚度及遮挡说明物体体积；先画后方表面，再画前方表面，避免用更多交叉线代替遮挡。只在有交互含义的位置使用强调线，线宽在缩放后仍清楚。插图自身不叠 UI 的投影、渐变、辉光或图片滤镜。

## 交互与自动演示

图库中的静态 SVG 用于缩略图和低成本占位。需要原位反馈时启用隔离交互画布，固定内核绘制 figure，模型源码始终留在 opaque-origin 的 `sandbox="allow-scripts"` iframe 内，不能动态导入到 Vue 文档或交给父页面执行。可见画布由固定宿主和图形 source 组装，不嵌入作品导入的 `html` 或 `previewHtml`。

应用组件的 `play` 参数可启用作品声明的 `tour`，由固定内核演示少量真实指针动作。指针进入或键盘聚焦画布时让出自动演示，离开并失焦后再恢复；方向键可依次探索 stops，Home 回到静止姿态。自动演示不抢夺用户位置，也不让读数持续向辅助技术播报。新生成图声明三至六个与真实手势对应的 stops，旧作品缺少 tour 时回退内核 `HL.LAP`。图形的交互是附加体验，业务按钮和图谱文字入口始终可用。

命中区域以静止物件位置计算，抬起、展开或回落不移动命中区域。连续追随采用弹簧，选中与展开等离散目标采用缓动；重复交互从当前数值重新定向，不先归零。动作停止后保留完整的静止姿态。渲染器更新路径和表面，父层不通过改变 iframe 的 CSS transform 伪造内部立体运动。

light、dark、milk 使用相同几何与时序，按当前主题的表面、文本、细节与强调角色实时取色。新作品可保存三种主题的 SVG 快照；旧图库没有 `milkSvg` 时仍用浅色快照。独立 HTML 保留固定 bench 的原生主题接口，页面主题适配由隔离画布的受控桥接承担。

## 关系与执行路径

关系图以真实有向边为依据。选择或悬停一个目标时，突出根到该目标的实际祖先路径，按层级逐跳响应；共享依赖与汇聚关系保留全部有效路径。离开悬停回到当前选中目标，静止节点中心继续承担命中，不能靠浮起后的图形位置判断是否仍在悬停。

工作流的节点、边和状态共用同一拓扑：源节点完成后沿该边传播信号，目标节点等所有输入信号到达后才执行，独立根可并行。边脉冲不按节点数组索引猜测顺序。后台或离屏不补算错过的动画时间，停止、重置、图编辑和卸载清理当前运行。减少动态效果按事件边界更新静态执行状态，关闭运动点与抬升。界面始终明确本地模拟；动效不代表已经连接 ComfyUI 或执行模型。

## 调度与验收

优先复用当前渲染器的循环，不为每个线段、节点或动效再建立 RAF。图形静止时停止更新。Hairline 可见画布在页面后台或离屏时卸载 iframe，以静态快照承接，返回视区后从静止姿态重新挂载；减少动态效果关闭自动 tour，手动探索即时更新。关系图的暂停与后台／离屏、工作流的后台／离屏冻结其逻辑时钟，恢复后从冻结进度继续。卸载释放图形、消息监听、观察器和运行状态。减少动态效果保留静态造型、选中路径、节点状态和全部操作。

人工检查静止、指针动作、缩略图、强度两端以及明暗主题，乳白再补一张主题画面。重点看轮廓是否可辨、遮挡是否正确、极值是否越界、悬停是否抖动和快速反向是否跳变。自动 `validation: "static"` 仅代表代码校验，不替代视觉验收。

接入还需检查场景独立选图、保存后刷新、旧图库导入、三种主题切换、指针／焦点接管、离屏和减少动态效果、非法消息及卸载。图谱检查祖先路径与汇聚依赖；工作流检查分支、汇聚、停止和重置，不能只对单链截图验收。未执行的浏览器、系统偏好或真实模型调用单独标注。
