# 验收
检查页面实际内容与主操作，不以截图替代交互。桌面和约 390px 验证布局、阅读、点击目标、媒体边框、横向溢出。键盘遍历导航、按钮、表单和弹窗；焦点可见，Esc 关闭并恢复。检查无效输入、加载、禁用、成功与复制失败。系统减少动态效果时仍完整显示内容。

以下材质检查以默认 light 为基准；两模式使用同一套设计、材料角色与状态行为。dark 切换背景、主题和文本配色，材质颜色与透明度按相同感知深度校准；圆角、尺寸、边框宽度、阴影方向/偏移/模糊/扩展、渐变位置和交互几何保持。逐项确认两模式均为左上受光、右下投影、凸面亮于基底、凹槽暗于基底，选中拨片浮起，按压转为内凹，不能因取反造成凸凹颠倒。对相同组件的默认、悬浮、按压、聚焦、选中、禁用和错误状态分别比较计算样式及实际视觉，不能仅核对主题令牌。检查首次默认 light、开关键盘可用、切至 dark 后刷新恢复、切回 light，以及已打开的 Portal 和 Canvas/WebGL/图表同步，见 [双模式主题](theme-modes.md)。

核对浅灰柔和拟物材料覆盖页面壳、控件、媒体、图表、关系、星空、园区与工作流。画布为 #e9eaee，极轻纸纹不影响读数，不呈现点阵网格、旧纸或折痕；正文、次字、焦点与操作保持可读。普通外框与现有结构边界采用 1px 半透明白边，图片区专用 3px 白色 rim，圆角连续，文字布局没有被额外套框。检查 Card 圆角浮起、按钮紧凑胶囊、输入与读数窗内凹、Tabbar 凹槽及选中拨片浮起；左上白色高光、右下灰色柔影与表面明暗协调，图片投影较清晰但边缘柔软。八类阴影按角色复用 assets/milk-tokens.css，悬浮与按压有可辨反馈；milk-relief 仅保留兼容，depth 为 0，没有伪元素硬底座或独立 isolation 结构。检查输入、下拉和 InputGroup、Tags、PIN/OTP 等复合输入容器聚焦时没有最外层 outline、Tailwind ring 或外边框变色，内部 inset 材质、光标及选中/状态提示仍可辨，正常 1px 半透明边框与柔影保持。普通按钮、Tab 与链接保留可见键盘 outline，dark 和 Portal 内重复验证；键盘操作、ARIA 与焦点恢复不变。图形内容线与状态文字保留，园区柔焦、散景粒子、扫描灯与余辉、太阳火焰、星体光晕和电流光尾继续可见。

运行安装、类型检查、生产构建和受修改影响的测试。技能运行 quick_validate 与 Markdown 引用验证。安装到隔离目录，不替换已安装技能。解压 .skill、ZIP、tar.gz，逐文件比较唯一源码，并实际下载。新项目创建自己的验收记录，说明时间、环境、证据和未执行项，不沿用源项目通过记录。

按键阻尼需验证普通按钮、Tab、开关及浮层触发器：快速点击仍有至少 88ms 按下反馈，90ms 轻微下沉后以 320ms 平稳回位，无弹跳、卡住或业务动作延迟；表面与阴影同步，返回正确的悬浮或选中材质。验证连续快速点击、长按后松开、Space／Enter、pointercancel、失焦与卸载，禁用项不触发，监听和计时器不残留。两模式使用相同运动参数，输入焦点规则保持；节点拖动、range 滑杆和 Portal 定位不受影响。系统减少动态效果时没有位移、缩放或过渡，但即时按压材质和操作仍可用。

组件库扩展需额外验证：Tab左右键/内容关联、滑杆键盘/开关禁用、图表图例/类型切换与数据表、神经/章鱼图节点选择、工作流节点拖动/连线/参数/导入错误/导出往返。工作流模型测试覆盖悬空端点、端口类型、循环连接和未知节点保真。

动态关系图需验证神经和章鱼两种连线光点沿路径前进、暂停冻结与继续恢复。星空仅显示五圈完整同心椭圆轨道，径向连线与电流光点隐藏，外围星体位于对应轨道。星空中的球面纹理水平自转，球体轮廓和标签不平面打转；太阳颗粒、日冕与日珥实际变化。外围行星倾斜相位随公转一周复位，自转调速不改变倾斜周期；星环随转轴变化并正确遮挡球体。逐节点设置恒星/行星皮肤，确认切换选择后配置仍保留；调速、重置、390px布局与键盘操作可用。验证 WebGL 渲染与 Canvas 2D 回退。减少动态效果和后台/离开视区时不继续循环，卸载无残留；未实际验证的系统设置或回退注明为未执行。

园区扫描需观察至少一个完整五秒周期：XYZ 轴与建筑地面使用相同投影，扫描方向经过楼栋时对应楼层／窗格点亮并留下衰减余辉，不能仅用全场统一呼吸代替命中反馈。暂停时扫描、粒子和余辉全部冻结；恢复从冻结相位连续推进，后台或离屏后返回不跳过一段扫描。验证约 390px 布局、减少动态效果下的完整静态场景及卸载后的循环清理。说明场景为演示数据，未验证的生命周期条件单独注明。
