# 验收
检查页面实际内容与主操作，不以截图替代交互。桌面和约 390px 验证布局、阅读、点击目标、媒体边框、横向溢出。键盘遍历导航、按钮、表单和弹窗；焦点可见，Esc 关闭并恢复。检查无效输入、加载、禁用、成功与复制失败。系统减少动态效果时仍完整显示内容。

以下材质检查以默认 light 为基准；两模式使用同一套设计、材料角色与状态行为。dark 切换背景、主题和文本配色，材质颜色与透明度按相同感知深度校准；圆角、尺寸、边框宽度、阴影方向/偏移/模糊/扩展、渐变位置和交互几何保持。逐项确认两模式均为左上受光、右下投影、凸面亮于基底、凹槽暗于基底，选中拨片浮起，按压转为内凹，不能因取反造成凸凹颠倒。对相同组件的默认、悬浮、按压、聚焦、选中、禁用和错误状态分别比较计算样式及实际视觉，不能仅核对主题令牌。检查首次默认 light、开关键盘可用、切至 dark 后刷新恢复、切回 light，以及已打开的 Portal 和 Canvas/WebGL/图表同步，见 [双模式主题](theme-modes.md)。

核对浅灰柔和拟物材料覆盖页面壳、控件、媒体、图表、关系、星空、园区与工作流。画布为 #e9eaee，极轻纸纹不影响读数，不呈现点阵网格、旧纸或折痕；正文、次字、焦点与操作保持可读。普通外框与现有结构边界采用 1px 半透明白边，图片区专用 3px 白色 rim，圆角连续，文字布局没有被额外套框。检查 Card 圆角浮起、按钮紧凑胶囊、输入与读数窗内凹、Tabbar 凹槽及选中拨片浮起；左上白色高光、右下灰色柔影与表面明暗协调，图片投影较清晰但边缘柔软。八类阴影按角色复用 assets/milk-tokens.css，悬浮与按压有可辨反馈；milk-relief 仅保留兼容，depth 为 0，没有伪元素硬底座或独立 isolation 结构。检查按钮、链接、输入、下拉、Tab、菜单项和可聚焦滚动区的焦点边框：单个 SVG 绘制约 2px 宽的内侧亮边，稳定轨道与约 5.2s 柔和渐变流光贴合圆角，没有额外外围 outline／ring，也不改变边框宽度、尺寸、布局和原有材质。InputGroup、Tags 只显示一处焦点边界，PIN/OTP 跟随活动格，dark 与 Portal 内重复验证；原有光标、选中/错误提示、键盘操作、ARIA 与焦点恢复不变。图形内容线与状态文字保留，园区柔焦、散景粒子、扫描灯与余辉、太阳火焰、星体光晕和电流光尾继续可见。

焦点还需验证鼠标、Tab／Shift+Tab、方向键与浮层焦点恢复：装饰跟随真实焦点，失焦或目标移除后不残留可见光效，卸载与 HMR 清理后不残留 SVG、监听或绘制循环，不阻挡点击或输入。减少动态效果时停止流动但保留静态亮边，forced-colors 使用 Highlight；不初始化控制器、不可装饰及清理后仍有可见键盘 outline 回退，不能全局无条件禁用焦点标识。

检查焦点流光的雾蓝、青玉与淡紫低饱和渐变及透明度连续过渡，首尾自然消隐，没有硬白亮头、突变色块或断开边框的明暗跳跃；单束光带贴合 2px 内侧边界，稳定银灰基线仍清楚，周期保持 5.2s。验证三个焦点光色令牌可自定义且随 light／dark 与 Portal 同步；彩色仅影响光带，减少动态效果时隐藏光带并保留静态基线，forced-colors 保留 Highlight。按钮悬浮时从指针进入处轻柔扩散一次表面波纹，持续停留不循环，移出再进入可重新触发；波纹不越过圆角、不遮挡文字，不改变尺寸、材质、按压阻尼及焦点边界。light／dark 及 Portal 都需验证，禁用与触摸不触发；减少动态效果不播放波纹，卸载与 HMR 清理后没有残留装饰、监听或动画。

检查 light、dark 及 Portal 中的纵向和横向滚动区域，覆盖 Textarea、Sidebar、Table／Data Table、Message Scroller 和 ScrollArea：纸感凹槽与圆角滑块协调，悬浮加深、拖拽压实，明暗同向受光。支持 ::-webkit-scrollbar 时使用 12px 完整样式，其余使用 thin／scrollbar-color 回退；ScrollArea 按 Reka hover／scroll 语义显现，滑块可拖且布局测量、视口尺寸正常，没有重复的原生滚动条。原有 scroll／auto 与内容范围保持，未全局隐藏滚动条或以 overflow:hidden／clip 裁切可滚动内容。用拖拽、滚轮／触控板、触屏与键盘验证可到达内容末端，独立滚动区按需提供焦点入口和名称，已有输入与 Reka 焦点语义不变；区域边界、标签及窄屏表格范围仍可辨。

运行安装、类型检查、生产构建和受修改影响的测试。技能运行 quick_validate 与 Markdown 引用验证。安装到隔离目录，不替换已安装技能。解压 .skill、ZIP、tar.gz，逐文件比较唯一源码，并实际下载。新项目创建自己的验收记录，说明时间、环境、证据和未执行项，不沿用源项目通过记录。

入场需验证首屏标题与主操作、滚动后的 Card／图片区块及异步加载的组件目录：700ms 渐显并从下方 18px 归位，分组以 80ms 错峰且最多延迟 240ms，滚动返回与主题切换不重播。查看筛选或路由产生的新元素是否正常显示；键盘直接聚焦待进入内容时立即可见。媒体的旋转、星体自转及节点定位不被入场覆盖。两模式和约 390px 下均不出现内容裁切或横向溢出；减少动态效果、缺少 IntersectionObserver 或控制器清理后内容立即完整可见，无残留透明状态、观察器或监听。

按键阻尼需验证普通按钮、Tab、开关及浮层触发器：快速点击仍有至少 112ms 按下反馈，100ms 轻微下沉后以 420ms 平稳回位，默认位移 2px、缩放 0.975，Tab 位移 1px，开关原位缩放 0.98；无弹跳、卡住或业务动作延迟，表面与阴影同步，返回正确的悬浮或选中材质。验证连续快速点击、长按后松开、Space／Enter、pointercancel、失焦与卸载，禁用项不触发，监听和计时器不残留。两模式使用相同运动参数，荧光焦点边框保持贴合；节点拖动、range 滑杆和 Portal 定位不受影响。系统减少动态效果时没有位移、缩放或过渡，但即时按压材质和操作仍可用。

Carousel 材质模式需观察切换中的实际状态：旧项投影和高光收起、变平并模糊淡出，新项在同一位置由虚化恢复清晰和浮起，无横向滑出、重影或残留装饰投影。以箭头、方向键与触摸拖动分别切换，检查首尾禁用、快速连续切换及中途反向，最终选中项与 Embla API 一致；只有活动项可点击、Tab 聚焦及被辅助技术访问。light／dark 与约 390px 下的卡片位置、尺寸和光向一致，调整尺寸、主题或重新初始化后不跳位。减少动态效果立即显示完整选中项，卸载后没有插件样式或监听残留；另查默认滑动模式仍支持原有并排 slide、插件与 API。未实际验证的输入方式或系统设置标注为未执行。

组件库扩展需额外验证：Tab左右键/内容关联、滑杆键盘/开关禁用、图表图例/类型切换与数据表、神经/章鱼图节点选择、工作流节点拖动/连线/参数/导入错误/导出往返。工作流模型测试覆盖悬空端点、端口类型、循环连接和未知节点保真。

动态关系图需验证神经和章鱼两种连线光点沿路径前进、暂停冻结与继续恢复。星空仅显示五圈完整同心椭圆轨道，径向连线与电流光点隐藏，外围星体位于对应轨道。星空中的球面纹理水平自转，球体轮廓和标签不平面打转；太阳颗粒、日冕与日珥实际变化。外围行星倾斜相位随公转一周复位，自转调速不改变倾斜周期；星环随转轴变化并正确遮挡球体。逐节点设置恒星/行星皮肤，确认切换选择后配置仍保留；调速、重置、390px布局与键盘操作可用。验证 WebGL 渲染与 Canvas 2D 回退。减少动态效果和后台/离开视区时不继续循环，卸载无残留；未实际验证的系统设置或回退注明为未执行。

园区扫描需观察至少一个完整五秒周期：XYZ 轴与建筑地面使用相同投影，扫描方向经过楼栋时对应楼层／窗格点亮并留下衰减余辉，不能仅用全场统一呼吸代替命中反馈。暂停时扫描、粒子和余辉全部冻结；恢复从冻结相位连续推进，后台或离屏后返回不跳过一段扫描。验证约 390px 布局、减少动态效果下的完整静态场景及卸载后的循环清理。说明场景为演示数据，未验证的生命周期条件单独注明。
