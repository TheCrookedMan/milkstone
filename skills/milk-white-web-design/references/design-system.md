# 纸感材质设计规范
以下以默认 light 为基准，两模式共用材料角色、几何和状态行为。dark 使用对应深色背景、主题和文本；高光与投影维持相同光照方向，颜色及透明度按相近的感知深度校准，不作机械反色。圆角、尺寸、阴影方向/偏移/模糊/扩展、渐变方向/色标位置、边框宽度和交互几何保持，见 [双模式主题](theme-modes.md)。

画布 #e9eaee；面板 #ebedf1；凸面 #eef0f4；浅亮面 #f4f5f8；凹槽 #e4e6eb；深面 #dfe2e8；兼容 --milk-warm 辅面 #e5e7ec；正文 #2e3540；次字 #5b6573；图形内容线 #cdd2db；焦点 #6b7c93。整体为协调的浅灰柔和拟物（soft neumorphic），圆角 Card 浮起，按钮呈紧凑胶囊，材料之间用轻微亮度差过渡。

白版使用左上白色柔和高光与右下灰色柔和投影表现浮起；Card、按钮和图片的投影按各自尺度调整，图片投影较清晰但边缘柔软。输入框和读数窗使用内凹阴影，Tabbar 是凹槽，选中拨片浮起，未选中项融入凹槽。dark 继续让左上受光、右下投影，凸面比相邻基底亮、凹槽比相邻基底暗；内凹阴影保留左上内暗与右下内亮，不把高光和暗部交换。按压切到凹面并保留小幅位移，悬浮略加强浮起，不再绘制硬边底座。

--milk-surface-raised 用于浮起顶面，--milk-surface-recessed 用于输入和 Tabbar 凹槽，--milk-surface-panel 用于面板；--milk-surface-side 保留兼容材料值，不用于硬侧面构造。页面保留极轻、不规则、静态纸纹，纹理不能抢占读数，不呈现点阵、旧纸或折痕。

light 普通外框与结构边界使用 1px 半透明白边，图片区专用 3px 白色 rim；dark 保留高光边的受光含义，并按深色表面的明度与透明度校准。--milk-border-width 为 1px，--milk-border-color 对应 #ffffff99，--milk-border-gradient 为 145deg 的 #ffffffc2 到 #ffffff38；具体参数以 assets/milk-tokens.css 为准。圆角外框可用 padding-box/border-box 分层，无圆角单边结构线可沿用 border-image；不为无边界文字布局额外套框。图形内容线与非输入控件的键盘 outline 保留信息含义。

八类真实阴影复用统一令牌，不在组件里任意堆叠。颜色、透明度、偏移和模糊以 assets/milk-tokens.css 为唯一参数来源：

| 令牌 | 用途 |
| --- | --- |
| --milk-shadow | 通用容器、相框等外浮柔影 |
| --milk-card-shadow | 圆角 Card 的外浮阴影与细高光 |
| --milk-card-hover-shadow | 可点击 Card 悬浮时稍加强的外浮柔影 |
| --milk-button-shadow | 按钮与选中拨片的小尺度外浮柔影 |
| --milk-hover-shadow | 按钮等小型实体悬浮时的外浮柔影 |
| --milk-pressed | 按压、输入和 Tabbar 凹槽的内凹阴影 |
| --milk-control-shadow | 小控件、功能槽的内凹阴影 |
| --milk-floating-shadow | Dialog、Popover、菜单与通知等浮层外浮柔影 |

milk-relief 及其 control/card/tabbar 角色类保留兼容，不再创建 ::before/::after 硬底座或 isolation 层叠结构；对应 depth 兼容值为 0。浮起与凹陷由表面和阴影角色承担。保留既有 absolute/fixed/sticky 定位；全局浮层继续 Portal/Teleport 到 body，组件功能伪元素保持原有用途。

页面字号：正文 16/1.65，说明 14/1.6，标签 12/1.5，标题 32/1.3，主视觉 46–68/1.2。中文不要大面积细字重。容器最大 1240px，桌面边距 40px、窄屏 22px。900px 以下单列，复杂布局可在 1024px 缩减列数。

## 组件排版与间距

组件内部复用 4、8、12、16、24、32px 间距，不把默认工具类的零散尺寸叠加成新的密度。紧密关联的图标与文字间隔 8px，标签与控件间隔 8px，紧密关联的字段或演示内容间隔 16px，独立 FieldGroup 与内容分区间隔 24px；成组操作间隔 12px。页面大标题与组件内部字阶分开使用，组件正文不跟随展示标题放大。

| 文字角色 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 组件正文、输入内容、卡片与弹层说明 | 14px / 1.65 | 400 |
| 字段标签、分组标签、普通按钮文字 | 13px / 1.5 | 500 |
| 辅助说明、时间、状态注记 | 12px / 1.5 | 400 |
| Card 标题 | 18px / 1.4 | 600 |
| Dialog、Sheet 等浮层标题 | 20px / 1.4 | 600 |

普通控件高度为 44px，small 为 36px、large 为 48px，独立图标按钮为 40px；紧凑规格用于有明确上下文的局部操作，不把全部界面压成紧凑密度。Card 内边距 24px，标题与说明间隔 8px，头部、内容与操作区间隔 24px；Dialog 内边距和分区间隔同为 24px。菜单内边距 8px、普通菜单项最小高度 36px。Tabs 凹槽内边距 6px、拨片间隔 4px、普通拨片高度 40px。更完整的组合约定见 [shadcn-vue 组件目录](shadcn-catalog.md)。

字阶和密度由根工程 `src/styles/shadcn-metrics.css` 统一实现，并随组件源码同步到技能 `assets/shadcn-catalog/src/styles/`；材质、阴影和交互状态继续由已有主题与运动令牌承担。明暗模式共用同一几何与字阶。窄屏 Card 内边距可收为 20px，操作区、Tabs 与字段组合优先换行或按语义滚动，不缩小标准字号和控件。长标题和说明允许自然换行，子项使用 `min-width: 0`，浮层不超出视口。

Calendar 的日期网格、Sidebar 的导航层级、Table 的列对齐及输入框内嵌图标或动作保留各自密度；不把普通按钮的高度、外边距批量施加给嵌套控件。紧凑结构仍使用共享字阶、清晰层级和足够命中区域。公共样式按组件语义作用，保留 props、插槽与用户传入 `class` 的扩展能力，不用全局 `!important` 覆盖布局尺寸。

面板圆角 24px、媒体 28px、输入框 12px、按钮胶囊 999px。按钮视觉紧凑，触控目标保持至少 44px。普通按钮、Tab 与链接的键盘焦点使用独立可见 outline。输入、下拉和复合输入容器（Input、Textarea、Select、Combobox、InputGroup、Tags、PIN/OTP）在 focus、focus-visible 或 focus-within 时不绘制最外层 outline、Tailwind ring，也不改变外边框颜色；以内部 inset 材质变化、光标、选中和状态提示表达焦点，保留正常 1px 半透明边框及柔影。dark 与 Portal 内控件使用相同规则，键盘操作、ARIA 和焦点恢复保持。正文与读数保持可读对比，不用模糊文字投影代替字形。默认、悬浮、按压、焦点、禁用与加载状态可辨。

图片使用 3px 白色 rim、圆角和较清晰的柔软投影，保留图像内容辨识与替代文本。真实图像用 img 和明确尺寸，需要统一图形内容时可灰阶处理；不把产品图片全部换成装饰图形。

UI 柔影与园区柔焦、扫描灯层及余辉、星体日冕光晕、电流光尾分别按其含义呈现；内容光学效果保留。系列与运行、成功、错误状态同时使用线型、形状、图标或文字，不只依赖亮度。实体控件见 [实体控件](instrument-components.md)，复杂图表与工作流继承同一材质和交互反馈。

## 文案规范

语气安静、清楚、有触感。以纸面、光影、层次和轻按回应描述体验，标题可用「纸上成形，触感有度」这类简短表达，正文接着说明实际能看到或操作的内容。浅色与深色共用同一套措辞，用「纸面」「面板」「高光」等材质角色描述共同体验；涉及具体模式时再说明浅灰或深灰配色。

按钮使用直接的动作名称，如「浏览组件」「保存设置」「重新扫描」；输入标签、占位提示、空状态和错误说明先帮助用户完成操作。按压、选中、加载和完成状态用准确的短句反馈，例如「已保存」「正在扫描」「请选择一个节点」。不把动作写成隐喻，不将未实现的后端、持久化或生成能力写成已有功能。

展示区的说明围绕内容与用途展开，技术名、版本、兼容范围和演示数据说明集中在相应目录、帮助或状态处。避免在每个组件中重复阴影参数与实现原理。中英文名称、操作名称与术语在落地页、组件演示、独立示例和技能资料中保持一致；英文组件及框架名保留官方拼写。
