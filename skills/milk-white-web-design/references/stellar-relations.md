# 电流关系线与星空图

需要连线光点、可配置星体皮肤、自转或公转时，使用 `assets/components/RelationStudio.vue`。它组合相邻 `StellarGraph.vue` 与 `StellarSurface.vue`；独立使用星空时也须保留后两者。关系布局使用 SVG，星体表面由 Canvas 中的原生 WebGL 着色器绘制，提供 Canvas 2D 回退；仅依赖 Vue 3.5+，无新增 npm 包或外部纹理。复制完整 assets 后在 component-lab 运行。

## 电流光点

神经图与章鱼图沿各自实际连接路径移动光点，亮核、柔和光尾和错开的相位形成电流感。光点从关系源移动到目标，基础连线及方向箭头始终保留；选中节点仍高亮直接关联。使用暂停控制查看静态关系，恢复从冻结相位继续。光点不代表工作流运行进度、真实权重或后端活动。

## 星空关系

中心太阳与五个轨道星体表达中心和分支关系。星空模式隐藏中心到星体的径向连线与电流光点，改用围绕太阳的五圈完整同心椭圆轨道；每颗外围星体沿对应轨道公转，轨道不使用断续线段。自转以球面经度的水平迁移呈现：围绕星体局部 Y 轴转动纹理，球体轮廓和标签不在屏幕平面打转。中心太阳保持直立；外围行星在水平自转的同时，转轴以 12° 的小锥角轻微倾向主体。`tilt` 与 `lean` 的相位直接取自各自公转角度，因此公转一周恰好完成一次倾斜周期；自转速度独立，不改变该周期。

星空容器与控件跟随当前主题，轨道、星点和标签按背景对比适配；星体皮肤与自然照明不做全场 RGB 取反。黑色模式下太阳仍发亮，日冕与日珥仍是发光，行星朝向太阳的一侧仍亮、背光侧仍暗；星体运动、纹理坐标、光照方向与轨道不变。需要适配的场景颜色在主题变化后重绘，暂停与静态模式同样响应，见 [双模式主题](theme-modes.md)。

太阳皮肤以翻涌颗粒、灰白日冕和卷曲日珥表现炽热等离子体，保持火焰燃烧般的动态轮廓。行星采用岩石坑纹、气体云带、冰质纹理和昼夜明暗；用灰阶纹理、亮度和球面光照区分皮肤，光照朝向中央太阳，不跟随表面纹理一起转动。星环随转轴朝向变化，分前后遮挡球体，不随自转相位在屏幕上旋转。星体、轨道、星点和光效在浅灰纸纹场景中保持灰阶，容器与控件使用统一灰白柔和拟物材质；轨道、星点与白色日冕通过灰色轮廓和柔影保持可见；背景星点使用确定数据，不在每帧产生随机星辰。火焰感是艺术化表达；示例不是燃烧、核聚变、行星岁差或轨道力学模拟。

通过画布上的星体或下方原生按钮选择节点，再为当前节点设置皮肤。可选恒星、岩石行星、气态行星、星环行星和冰晶行星；切换节点不会把其他节点的皮肤一并替换。自转与公转速度可分别调节，暂停冻结星体转动与表面动态，重置恢复示例。配置保存在当前页面内存；移植到产品时可由业务模型提供皮肤、灰阶光照、半径和关系，明确持久化方式。

## 运行与可访问性

`StellarSurface.vue` 接收 `skin`、`spin`、`tilt`、`lean`、`lightX`、`lightY` 与 `time`；角度用度，时间用秒。父组件传入朝向主体的光照向量及已管理的经过时间；渲染区域宽高为星体半径的 3.6 倍，为日冕和星环留出空间。不要把整个 canvas、球体外框或标签做 CSS 平面旋转。

每个组件实例用唯一 SVG ID，避免渐变与滤镜引用冲突。星空小屏按容器缩放；原神经/章鱼图使用自己的可滚动画布，不能令整个页面横向溢出。移动星体之外保留位置稳定的节点按钮、当前节点详情与设置标签，键盘选择和皮肤设置不依赖追逐动画目标。

父组件的 `requestAnimationFrame` 以实际时间增量驱动公转、自转和表面时间，相位在暂停时保留；表面组件只在输入变化时绘制，不另建持续计时器。可见性以实际星空画布为准，滚动或切换尺寸后重新核对画布位置。减少动态效果、页面后台或画布离开视区时停止循环；恢复时清空上帧时间，避免补跳后台时间。暂停、重置和换模式后的行为应保持一致。卸载时取消 RAF，断开观察器，移除事件监听并释放 WebGL 资源。

## 验收重点

- 神经/章鱼光点在真实路径上移动，暂停前后位置保持不变，继续后恢复移动。
- 星空仅显示五圈完整同心椭圆轨道，不显示径向连线和电流光点；外围星体始终位于各自轨道上。
- 太阳纹理沿球面水平迁移，日冕与日珥翻涌；球体轮廓和标签保持稳定，不能只是平面贴图打转。
- 行星自转与公转分别变化；倾斜相位等于公转相位，一周后复位。调节自转速度不改变倾斜周期，星环前后遮挡与朝向正确。
- 每类皮肤以不同灰阶肌理与光照实际改变星体外观；逐节点设置互不覆盖，调节两种转速有效，重置还原示例。
- 390px 下画布和设置可用，页面没有横向溢出；节点按钮和所有设置可用键盘完成。
- 切换模式保留页面中的星空配置，隐藏的动画停止。系统减少动态效果保留静态关系和设置；未实际执行的系统切换验收需明确记录。
