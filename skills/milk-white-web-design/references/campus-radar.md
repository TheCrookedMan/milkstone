# 园区雷达扫描

园区容器与控件以默认白色模式为基准；黑色模式使用深色主题并保持相同凸起与凹槽感。Canvas 的背景、坐标、网格和标签按角色适配，建筑受光面、阴影、扫描亮层、粒子与余辉保持自然明暗关系，不把发光反成暗斑；在 `milk-theme-change` 后重绘。暂停与减少动态效果下也能更新主题，扫描相位、五秒周期与投影保持，见 [双模式主题](theme-modes.md)。

`assets/components/CampusRadar.vue` 提供原创 Canvas 2D 等距园区。浅灰纸纹画布与灰白柔和拟物控件承托场景，灰白柔焦楼群、漂浮粒子与清楚的 XYZ 轴共同呈现空间；雷达扫描经过楼栋时亮起带灰边对比的白色楼层／窗格，并保留短暂余辉。建筑侧面、顶面、粒子与扫描光使用灰阶亮度，XYZ 轴以文字和线条区分方向；该图形规则不要求 UI 材料改为中性灰。适用于园区、小区或数字孪生概念展示；当前几何与状态均为演示数据，不代表已连接地图、楼宇设备或 IoT 接口。

## 投影与命中

世界 Y 轴向上，X/Z 构成地面。建筑、网格、坐标轴与雷达使用同一套世界到画布的投影，避免扫描只覆盖屏幕装饰区域。保持楼栋的体积、层高与遮挡关系；柔焦用于营造距离和空气感，坐标文字与控制文字保持可读。

固定每 5000ms 完成一圈扫描，以楼栋在 X/Z 平面的方位判定扫过，再驱动楼层／窗格发光与衰减。处理角度跨越零点及低帧率时的扫过区间，避免部分楼栋漏亮。不要用与扫描方位无关的统一闪烁替代命中反馈。

## 时钟与复用

扫描、粒子和余辉共享可暂停的场景时间。用户暂停、离开视区、页面进入后台或系统要求减少动态效果时停止持续循环；恢复时从保存相位继续，不把暂停时长计入场景时间。减少动态效果时仍呈现建筑、坐标与扫描信息的静态状态，用户可明确选择播放该演示；卸载清理动画帧及观察器。

该组件仅依赖 Vue 和浏览器原生 Canvas 2D，无外部图片、纹理或新增包。复制组件及样式令牌后在 Vue 模板中使用 `<CampusRadar />`；画布随容器尺寸和像素密度调整，约 390px 时轴标签与控件仍须可读。真实项目可用业务适配层替换演示布局和状态，保留投影、时间与扫描命中的一致性。
