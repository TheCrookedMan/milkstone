# Milkstone 展示页

页面采用逐步展开的入场效果：首屏标题、说明与主操作，以及进入视区的面板、Card 和媒体包装层，以 700ms 渐显并从下方 18px 归位；分组子项每隔 80ms 错峰，延迟最多 240ms，每个元素只播放一次。异步内容与筛选后的新元素由共享观察器登记，媒体旋转与画布动画保留。按钮按下使用 100ms 下沉、至少 112ms 材质反馈和 420ms 平稳回位；默认位移 2px、缩放 0.975，Tab 为 1px，小开关原位缩放 0.98，业务操作立即执行。light／dark 复用同一节奏，键盘聚焦时立即显示内容，系统减少动态效果时保留完整静态内容与即时按压材质。接入与验收规则见技能 [交互规范](../skills/milk-white-web-design/references/motion-and-network.md)。

`/#/#empty-states` 展示暂无数据、暂无用户与筛选无结果，并提供 Prompt 生成与个人图库。新图通过配置好的生成 API 调用真实大模型，按 Hairline Create 的 figure 接口组装与静态校验，再在隔离环境中绘制明暗预览；服务未配置或生成失败时明确提示。用户可保存生成图形、选择已有图、导入／导出图库 JSON 及下载交互 HTML，已有图无需重复调用模型。初始空托盘与添加、筛选、重置仍可离线演示；业务数据操作只作用于当前页面。`/#/#shadcn` 的 Empty 示例沿用同一插图语言。生成与接入规则见 [空状态插图](../skills/milk-white-web-design/references/empty-state-illustrations.md)，服务启动与缓存边界见 [Hairline 模型服务](../skills/milk-white-web-design/references/hairline-generation-service.md)。

根工程只使用 pnpm。运行 pnpm install、pnpm typecheck、pnpm test、pnpm build。使用 pnpm dev 预览，开发和生产预览默认监听 0.0.0.0:4340，同一局域网的其他电脑可通过 http://<本机局域网IP>:4340/ 访问；本机仍可使用 http://127.0.0.1:4340/。默认 light 覆盖页面壳、70 项 shadcn-vue 与五个领域工作台：#e9eaee 浅灰画布保留极轻随机纸纹，灰白表面使用左上白高光和右下灰柔影。Card 圆角浮起，胶囊按钮紧凑，输入与 Tabbar 为凹槽，选中拨片浮起；普通边框 1px 半透明白，图片专用 3px 白 rim 与较清晰柔软投影。八类阴影按容器、Card、按钮、内凹控件和浮层角色复用，数值以 CSS 为准。milk-relief 类保留兼容、depth 为 0，不绘制伪元素硬底座或 isolation 实体结构。仅真实输入框、Textarea、contenteditable、PIN/OTP 活动格和 Command/Combobox 输入保留内侧焦点流光；复合输入只在编辑器聚焦时亮起，内部按钮聚焦不亮起。输入框未接管时保留静态键盘边界回退。按钮、Tab、链接、Select 触发器、开关、滑杆及容器等其他元素不新增焦点 outline、ring、边框变色或流光，正常材质边框、柔影和选中状态保持，三种主题与 Portal 一致。图形内容线保留信息含义；园区柔焦、扫描灯、星体光晕与电流光尾继续保留。三个独立示例使用相同规范。dark 与 light 共用设计、材料角色和状态行为，背景、主题与文本使用对应深色配色；材质颜色与透明度按相近感知深度校准，左上继续受光、右下继续投影，凸面比基底亮、凹槽比基底暗，选中 Tab 仍浮起。渐变位置、阴影几何、字体、尺寸与布局保持。Portal 与图表按同一语义令牌适配，图片、星体和建筑保留自然照明，不使用整页 filter。新增 milk 乳白以牛奶柔白 #f4f1ea 为画布、暖白凸面 #fbf9f4 与浅暖灰凹槽 #e9e4da 形成层次，左上暖白高光与右下暖灰投影保留相同光照方向，以更短偏移、更小模糊和紧密接触影加强 Card 与按钮的实体感；字体、间距、纸纹密度与阻尼保持。主题入口使用白色／黑色／乳白三个原生单选项，选择以 milk-design-theme 记住，接口见技能 [三种主题](../skills/milk-white-web-design/references/theme-modes.md)。公开验证范围与未执行项见 [验证记录](verification.md)。
