# 验证记录

公开版本：Milkstone 1.7.0。最后核对：2026-10-10。

## 自动检查

- 主工程 Vue / TypeScript 类型检查。
- 36 项 Node 测试：安装器、归档 CLI、工作流模型、主题与按压反馈。
- 生产构建，包括技能源码同步和三种归档生成。
- 技能 frontmatter 与 Markdown 相对引用校验。
- 独立 shadcn-catalog 使用同一组件源码通过类型检查。
- 三种技能归档与技能源目录按文件内容一致。

GitHub Actions 使用 Node.js 24.10.0 和 pnpm 10.18.3，运行类型检查、测试、生产构建、技能校验和独立组件目录类型检查。

## 浏览器检查

当前 70 项组件在原窗口、1280px 和 390px 视口配置中检查过 light / dark 排版，页面无横向溢出。检查包括日期翻页、六位 OTP、数字输入、下拉选择、Tabs、弹窗 Esc 关闭与焦点返回、确认弹窗、收藏与折叠面板。

早期领域组件检查包含图表系列切换、关系模式及动画暂停、星体皮肤和公转、园区扫描，以及工作流编辑和 JSON 往返；具体实现范围以各组件参考文档为准。

预览图片来自实际页面截图；组件尺寸与字阶通过浏览器计算样式核对。

## 已知限制

- ECharts / ChartStudio 与组件目录的生产分包仍有 Vite 默认 500kB 提示，构建通过。
- 未执行完整屏幕阅读器审计或 Safari / Firefox 跨浏览器测试。
- 系统减少动态效果和后台可见性分支有代码保护；并非每一项都做过操作系统级实测。
- 未连接真实 ComfyUI 服务、模型或业务后端。
- 宿主文件安装测试通过不等于已验证所有 Agent 的实际加载或账户插件启用。
